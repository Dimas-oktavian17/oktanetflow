# Lab 01: Quick Setup SPSS & AMOS

## 1. Prerequisite

- Windows 10/11 Operating System.
- SPSS and AMOS installer packages (including crack/fix files).
- Administrator privileges on the target machine.

## 2. Configuration

### 2.1 SPSS & AMOS Software Installation

1. **Extract Files:** Fully extract the downloaded software package zip/rar archive before executing.
2. **Run Installer:** Right-click the primary `setup.exe` or installer file within the software folder and select **Run as Administrator**.
3. **Follow Installation Wizard:** Proceed through the standard setup prompts. Accept the terms and click **Next** until the installation phase finishes.
4. **Do Not Launch:** Uncheck any options to automatically launch or start the software application immediately upon completion. Click **Finish**.
                  
### 2.2 License Bypass (Crack Integration)

To activate the software without an official license authorization key, perform the manual file replacement workflow below:

1. **Locate Patch Files:** Navigate back to the extracted setup directory and open the folder named `Crack`, `Fix`, or `Patch`.
2. **Copy Activation File:** Locate the target license override file (commonly named `lservrc` or a custom `.dll` file), right-click, and select **Copy**.
3. **Open Destination Directory:** Navigate to the core installation paths on your root drive:
   - **SPSS Statistics:** `C:\Program Files\IBM\SPSS\Statistics\[Version]\`
   - **AMOS Graphics:** `C:\Program Files (x86)\IBM\SPSS\Amos\[Version]\`
4. **Execute Replacement:** Paste the copied activation file directly inside the target directory. When prompted by Windows User Account Control, select **Replace the file in the destination**.

## 4. Verification & Troubleshooting

- Ensure that the software applications are properly installed and accessible from the start menu.
